# 如何撰写并发布一篇新文章

这篇文章是写给未来的自己的使用说明书——告诉你如何在这个博客上发布一篇新的技术文章。只需要两步。

## 第一步：创建 Markdown 文件

在项目的 `posts/` 目录下，新建一个 `.md` 文件，文件名建议使用英文下划线命名，例如：

```
posts/
├── Hello_World.md
├── About_GitHub_Pages.md
├── How_To_Write_Article.md   ← 你现在看的就是它
└── 你的新文章.md              ← 你要创建的
```

在 VS Code 中，直接右键 `posts` 文件夹，选择"新建文件"，输入文件名即可。

## 第二步：注册到 manifest.json

打开 `posts/manifest.json`，按照已有的格式添加一条记录：

```json
[
  {
    "name": "你的新文章.md",
    "title": "文章的中文显示标题",
    "date": "2026-03-01",
    "tags": ["标签1", "标签2"],
    "path": "posts/你的新文章.md"
  }
]
```

**字段说明：**

| 字段 | 含义 |
|---|---|
| `name` | 文件名，会显示在侧边栏 |
| `title` | 文章的中文标题（目前备用） |
| `date` | 发布日期，格式 `YYYY-MM-DD` |
| `tags` | 文章标签数组，显示在面包屑区域 |
| `path` | 相对于网站根目录的文件路径 |

## Markdown 写作技巧

### 标题层级

```markdown
# 一级标题（文章主题，每篇只用一个）
## 二级标题（主要章节）
### 三级标题（小节）
```

### 代码块

用三个反引号包裹代码，并指定语言以获得语法高亮：

````markdown
```python
def hello():
    print("Hello, Blog!")
```
````

### 表格

```markdown
| 列一 | 列二 | 列三 |
|------|------|------|
| 数据 | 数据 | 数据 |
```

### 引用

```markdown
> 这是一段引用，背景会变成特殊样式。
```

效果：

> 这是一段引用，背景会变成特殊样式。

---

完成这两步之后，将代码 `git push` 到 GitHub，新文章就自动上线了。就这么简单！
